SPECTRE | SFI

Privacy Policy

Effective November 24, 2026

1. Overview

Spectre Fantasy Intelligence (SFI) is an independently operated personal fantasy football intelligence project maintained by SpectreNJ. It is intended for private personal use and is not a public commercial service.

2. Information Collected

SFI retrieves fantasy football information through the Sleeper API, including:

  • League settings and configurations
  • Fantasy team names and manager identifiers
  • Player information and roster assignments
  • Matchup results and fantasy scoring
  • Waiver claims and completed transactions
  • Historical league performance and analytics

3. Google Drive Access

SFI uses Google OAuth 2.0 and the Google Drive API with the following permission scope:

https://www.googleapis.com/auth/drive.file

This permission allows SFI to create, read and update files authorized for use by the application. SFI does not request unrestricted access to the operator's Google Drive.

Google Drive access is used to store fantasy football intelligence exports, update the latest intelligence file, preserve historical season archives and verify file integrity.

4. Use of Information

Collected information is used for personal fantasy football analysis, roster management, historical research, performance evaluation and decision support.

5. Data Storage and Security

Intelligence files are stored in the project operator's Google Drive account. Automated processing is performed through GitHub Actions using a private repository.

OAuth credentials are stored using GitHub Actions encrypted secrets. Temporary intelligence exports may also be retained as private GitHub workflow artifacts.

6. Data Sharing

SFI does not sell Google user data or use it for advertising.

The project operator may authorize connected services, including ChatGPT, to retrieve and analyze intelligence files for personal fantasy football decision support. Such access is subject to the permissions and privacy policies of those services.

7. Data Retention and Deletion

Historical intelligence files may be retained for long-term fantasy football analysis. The project operator may delete these files directly from Google Drive and remove temporary exports from GitHub.

8. Revoking Access

Google account authorization may be revoked at any time through the Google Account connections page:

Manage Google Account Connections

Revoking authorization prevents future authenticated access but does not automatically delete previously created intelligence files.

9. Google API Compliance

SFI's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

10. Policy Updates

This privacy policy may be updated as the project develops or its data processing practices change.

11. Contact

Questions regarding this policy may be directed to the project operator through the SpectreNJ GitHub profile.
